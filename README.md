# 🏨 Sistema de Gestión de Reservas de Hotel

Este es un sistema completo de gestión de reservas para un hotel desarrollado en Python. Permite registrar clientes, gestionar habitaciones, hacer y cancelar reservas, procesar pagos y generar reportes, todo desde una interfaz de consola.

---

## 📌 Funcionalidades principales

- 📋 Registro y visualización de clientes
- 🛏️ Gestión de habitaciones y disponibilidad
- 📆 Creación y cancelación de reservas
- 💳 Procesamiento de pagos (asincrónico)
- 📄 Generación de reportes mensuales
- 👤 Control de acceso por roles de empleados

---

## 🧠 Tecnologías utilizadas

- Python 3.10+
- Programación Orientada a Objetos (POO)
- Programación asincrónica con `asyncio`
- Decoradores personalizados para control de acceso
- Módulos y paquetes personalizados
- Gestión de fechas con `datetime`

---

## 🧑‍💼 Roles definidos

- Receptionist
- Manager
- Administrator
- Cleanliness
- Counter

Cada rol tiene permisos específicos para acceder a funcionalidades del sistema.
